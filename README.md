# Flink Helper Dresden

Личный помощник курьера: своя карта с маршрутом по велодорожкам, заметки по адресам, немецкие фразы с транскрипцией, помощник звонка клиенту, чек-лист смены, справочник ПДД.

- Работает офлайн (PWA), ставится на Android как приложение.
- Адреса, коды и заметки — только на телефоне (IndexedDB), никуда не отправляются.
- Поиск координат адреса — по офлайн-базе OSM на телефоне.
- В сеть уходят только запросы тайлов карты ([OpenFreeMap](https://openfreemap.org)) и координаты начала/конца маршрута ([BRouter](https://brouter.de)).
- Без сборки: чистые HTML/CSS/JS, карта — [MapLibre GL JS](https://maplibre.org) (лежит в `vendor/`).

## Проверка на компьютере

```sh
node tools/serve.mjs      # → http://localhost:8080
node --test tests/*.test.mjs   # тесты разбора адресов и геокодера
```

## Установка на телефон (GitHub Pages, бесплатно)

1. Создать публичный репозиторий на GitHub и загрузить туда файлы проекта
   (`.gitignore` не пропустит личный план и резервные копии).
2. Репозиторий → Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту приложение доступно по адресу `https://<логин>.github.io/<репозиторий>/`.
4. Открыть этот адрес в Chrome на телефоне → меню ⋮ → «Добавить на главный экран» / «Установить приложение».

На GitHub лежит только код — адреса и заметки остаются в телефоне.

## Обновление

Файлы приложения загружаются «сначала из сети», поэтому изменения видны при следующем запуске.
Если меняется список файлов в `sw.js` — увеличить версию `CACHE`.

Обновить базу адресов Дрездена (раз в несколько месяцев):

```sh
node tools/build-addresses.mjs   # скачивает из Overpass → data/addresses-dresden.json
```

## Структура

| Файл | Что внутри |
|---|---|
| `js/data.js` | Фразы, помощник звонка, чек-лист, ПДД — редактировать здесь |
| `js/app.js` | Экраны и логика |
| `js/map.js`, `js/map-style.js` | Карта, GPS, маршрут; стиль карты (что показывать и каким цветом) |
| `js/geocode.js` | Координаты адреса по офлайн-базе OSM |
| `js/address.js` | Разбор адреса из Flink, поиск |
| `js/db.js` | Локальное хранилище |
| `sw.js` | Офлайн-кэш |
